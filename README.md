# timeseries-api

## SmartLight
Get all SmartLights by last minutes:
https://smartcampus-k8s.maua.br/api/timeseries/v0.2/SmartCampusMaua/SmartLight/all?interval={time in minute}

Get SmartLight by `deviceId`:
https://smartcampus-k8s.maua.br/api/timeseries/v0.2/SmartCampusMaua/SmartLight/deviceId/{deviceId}?interval={time in minute}
